# SketchMath Fillet Feature Contract

Updated: 2026-08-09

Status: passed for a default-off extrusion-to-terminal-fillet STEP envelope; overall `SM-FEAT-005` remains partial

## Enablement

- backend creation: `FRIDAY_SKETCHMATH_FILLET_FEATURES_ENABLED=1`
- guarded browser editor: `REACT_APP_SKETCHMATH_FILLET_FEATURES_ENABLED=1`
- STEP execution also requires the document/artifact-job flags and a configured or discoverable `FreeCADCmd`

All flags default to off.

## Canonical Contract

A fillet feature stores a positive finite `radius_mm`, exactly one same-body dependency, and one or more semantic edge selectors. Supported selectors resolve to convex `vertical_outer_edge` references generated by a polygonal extrusion. Each reference carries producing feature, role, source/adjacency identity, ordinal, geometric signature, 3D endpoints, corner class, and a radius bound derived from adjacent sketch edges.

Rebuild resolves references as exact or recovered and refuses missing, ambiguous, duplicate, non-vertical, concave, or oversized selections. It generates stable `fillet_surface` semantic records and a deterministic feature signature. Rebuild does not invent analytic post-fillet volume: the record has `measurement_coverage=kernel_required` and no measurements until a validated artifact is built.

## Kernel Boundary

The revision-bound STEP job currently accepts exactly this body graph:

1. one independent positive, one-sided new-body extrusion;
2. one terminal fillet over one or more supported convex outer vertical edges.

The worker reconstructs the base solid, enumerates FreeCAD edges, and matches each semantic selector by unordered 3D endpoints within tolerance. Every selector must resolve to exactly one unused kernel edge. A transient FreeCAD edge ordinal is retained only as diagnostic artifact metadata; it is never persisted as the canonical reference.

After `makeFillet`, the worker requires a valid positive solid, unchanged supported bounds, and measurable material removal. It writes STEP plus validation metadata containing base/final volume, radius, semantic-to-kernel resolution, worker/runtime identity, and content hash. Failure leaves the committed feature graph unchanged and the artifact job visibly `FAILED`.

## Browser Behavior

For a document containing one supported extrusion, the guarded panel exposes a radius and `Fillet outer edges`. It selects all generated convex outer vertical edges semantically. The committed fillet row exposes radius replacement, feature undo/redo, `Build STEP`, persistent job state, retry, download, and reload recovery.

## Explicitly Open

Arbitrary edge picking, concave/horizontal/curved edges, multi-stage body graphs, fillet STL, downstream kernel-topology reconciliation, and fillets on the seven-feature golden mounting plate remain open. Equal-distance chamfer now shares this selector and kernel-job discipline as documented in `chamfer_feature_contract.md`; neither edge finish completes `SM-FEAT-005` or the final golden-part scenario.
